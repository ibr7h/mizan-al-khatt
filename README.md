# ميزان الخط — Mizan Al-Khatt

مشروع PWA مستقل لتعليم **هندسة الخط العربي**: ميزان النقاط، خط الارتكاز، خط القمة، اتجاه الضربات، التتبع والكتابة الحرة.

## الإصدار الحالي
`v0.1.0` — نموذج مرجعي أول لحرف **الألف المفردة في خط النسخ**.

## فلسفة المعمارية
- بيانات كل حرف منفصلة عن واجهة التطبيق (`data/alif.json`).
- النموذج الهندسي Vector/SVG وليس صورة ثابتة.
- محرك التدريب منفصل عن بيانات الحروف لتسهيل إضافة بقية الحروف لاحقًا.
- جميع القياسات نسبية إلى نقطة القصبة، بحيث يمكن لاحقًا معايرة الحجم آليًا مع عرض القلم.

## أوضاع الإصدار الأول
1. **الشرح**: الحرف بين خط القمة وخط الأساس، خمس نقاط قياس، سهم اتجاه الضربة.
2. **التتبع**: نموذج شبح مع الرسم فوقه وحساب درجة تقريبية لمسار الألف.
3. **الكتابة الحرة**: خطوط القياس فقط مع مساحة تدريب مفتوحة.
4. **ورقة التدريب**: صف نموذجي وصفوف شبحية على نمط أوراق التدريب المرجعية.

## ملاحظة مهمة
هندسة الألف الحالية **Reference Draft** وليست اعتمادًا نهائيًا لقياسات المدرسة الخطية. عند تزويد المشروع بالنموذج المعتمد لكل حرف يتم استبدال `svgPath` والقياسات في ملف البيانات دون إعادة بناء المحرك.
